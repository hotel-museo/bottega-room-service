메뉴 추가 / 카테고리 추가

새 메뉴와 새 카테고리 추가 기능을 이 화면에서 바로 사용합니다.

메뉴관리는 한국어만 수정합니다.
메뉴명 · 메뉴설명 · 카테고리를 모두 정리한 뒤 전체 번역을 한 번 눌러 영어 · 일본어 · 중국어를 일괄 갱신합니다.
개별 번역 검수와 수정은 왼쪽 번역관리 페이지에서 할 수 있습니다.

카테고리 순서

카테고리 이름 수정 · 삭제 · 노출 순서 변경을 할 수 있습니다.

카테고리의 이름수정 버튼으로 이름을 변경할 수 있습니다. 드래그로 순서를 바꾼 뒤 아래의 전체 순서 저장을 누르면 메뉴 순서와 함께 저장됩니다.

메뉴 순서 / 품절 관리

☰ 아이콘으로 메뉴 순서를 바꾸고, 메뉴를 더블클릭하면 상태 관리창이 열립니다.

드래그: 메뉴 순서 변경 · 더블클릭: 이름수정 / 설명수정 / 가격수정 / 카테고리 변경 / 숨김 / 품절 기간 설정

전체 페이지

주문페이지의 기본 글씨체, 글씨색, 배경색과 배경사진을 설정합니다.

등록된 배경사진이 없습니다.

BOTTEGA 간판

상단 BOTTEGA 간판의 배경, 글씨체와 글씨색을 설정합니다. 배경사진이 등록되어 있으면 배경색 위에 사진이 표시됩니다.

등록된 간판 배경사진이 없습니다.

언어 선택 버튼

한국어 · ENGLISH · 日本語 · 中文(简体) 언어 버튼의 글씨체, 글씨크기와 글씨색을 설정합니다.

버튼 / 카테고리

주문페이지의 선택된 카테고리와 주요 버튼 색상을 별도로 설정할 수 있습니다.

실시간 확인

색상·폰트·사진 선택은 저장 전에도 즉시 미리보기에 반영됩니다. 실제 주문페이지 적용은 디자인 설정 저장을 눌러야 완료됩니다.
